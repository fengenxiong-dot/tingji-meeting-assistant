# 听记君 · 会议与面试记录助手

把会议和面试中的声音，整理成可以回看、检索和复用的工作记录。

[项目主页](https://github.com/fengenxiong-dot/tingji-meeting-assistant) · [作者与项目合集](https://github.com/fengenxiong-dot) · [许可证](LICENSE)

## 为什么做这个工具

在人力资源工作中，面试、沟通访谈和项目会议经常连续发生。边听边记容易漏掉细节，会后整理又会占用大量时间。这个项目从“先保留原始内容，再辅助整理”的需求出发，尝试把录音、转写、总结和历史检索放在同一个本地工作台。

## 核心功能

- 通过电脑麦克风录音，支持暂停、继续、结束存档和音频回放。
- 支持会议与面试两种整理场景；面试初步评价仅作辅助观察。
- 通过配置的语音服务分段转写，通过语言模型生成阶段总结及最终总结。
- 支持人工修改转写和总结，保留总结历史版本。
- 按标题、参与人、日期和原文检索；跨记录问答可显示来源片段。
- 支持 Markdown 导出，以及面试总结的 Word 导出；记录可进入回收站并恢复。

## 适合哪些场景

- 招聘面试后整理核心问答，方便复盘。
- 培训需求访谈、员工沟通和项目会议的记录与检索。
- 查找某次会议中的结论，并回到原文与音频核对。

## 第一次使用

### 准备环境

Node.js 24 或以上；建议 Windows + Edge/Chrome。AI 转写和总结需要你自己的服务商账号与 API Key。

下载方式：会使用 Git 可按下面的命令克隆；也可在本页点击 **Code → Download ZIP**，解压后在项目目录打开终端，跳过 `git clone` 和 `cd` 两步。

### 安装与启动

```sh
git clone https://github.com/fengenxiong-dot/tingji-meeting-assistant.git
cd tingji-meeting-assistant
npm ci
npm start
```

打开 `http://127.0.0.1:4317`。Windows 也可使用 `start.cmd` 启动浏览器版。

### 操作流程

1. 在“模型与设置”配置语音转写和语言模型，先测试连接。
2. 选择会议或面试场景，允许浏览器访问麦克风，开始录音。
3. 需要临时离开时暂停；结束时选择结束并存档，等待转写与总结完成。
4. 核对原文、修改总结并补充参与人，再导出需要的内容。
5. 以后可从全部记录或档案助手检索，并通过来源卡片回看原文。

## 当前状态与限制

这是源码版，仓库不包含现成 EXE。需要桌面版时可安装开发依赖后运行 `npm run desktop`，自行打包用 `npm run build:win`。麦克风录音、真实模型与长时间连续使用需自行试录；语音转写存在分段等待时间。当前版本不提供说话人区分、录音笔导入或电脑内部音频采集。录音保存在本地；调用转写或总结服务时，相应音频或文字会发送给你配置的服务商。

**验证情况：** 本次发布检查了源码结构与 Python 文件语法（如有），未重新完成本项目全套端到端验收。项目提供 `npm test`。

## 数据保存与配置

运行数据位于 `data/`，包含录音、文字和配置；备份前先停止录音并退出服务。

公开仓库只提供源码与示例配置。真实人员资料、业务文件、数据库和 API Key 需要由使用者自行管理。先用虚构数据走通流程，确认符合自己的需求后再投入实际工作。
