# 你好，我是 fengenxiong-dot

**人力资源从业者 · 零基础、零代码起步 · 用 Web Coding 与 AI 辅助开发解决工作问题**

我本身在人力资源行业工作，没有传统编程基础。这些项目来自我的工作场景，以及支持这些工作的学习、表达和日常办公需求。

我通过 Web Coding 的方式实践开发：用自然语言描述需求，借助 AI 完成代码实现，再围绕真实流程试用、反馈和持续调整。我主要投入的是对业务场景的理解、需求拆解、流程设计和使用体验。

这个账号记录我如何把“工作中需要一个这样的工具”，一步步变成可以运行、可以分享、可以继续改进的项目。

## 我关注的工作场景

- **招聘与沟通**：面试记录、访谈整理、会议复盘。
- **培训与学习**：培训测验、课程录制、讲稿提词和资料学习。
- **人才管理**：人才盘点、在线评价、任职资格标准与认证流程。
- **办公与 AI 应用**：Word 文书填充、PDF 材料整理，以及钉钉中的 AI 使用入口。

## 我怎样做这些项目

1. 从工作中的重复操作、流程断点或信息整理难题出发。
2. 把使用者、任务、输入和输出描述清楚。
3. 用自然语言与 AI 协作，逐步做出可试用的版本。
4. 用虚构样例和实际操作反馈检查流程，继续调整。
5. 把可复用的源码和经验整理出来，分享给有相似需求的人。

我仍在学习和迭代。这些仓库是持续完善的实践作品，各项目的功能范围、环境要求和验证情况，请以各自 README 为准；开源并不意味着已经适配所有企业或部署环境。

## 怎样开始使用

先选择与你的工作问题最接近的项目，阅读其中的“适合哪些场景”和“第一次使用”。有些是本地小工具，有些需要数据库、模型服务或钉钉应用配置，准备成本不同。

所有项目都只分享源码和示例配置，不提供真实人员资料、企业业务数据或账号密钥。建议先用虚构数据体验完整流程。
